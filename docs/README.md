# 할인금액 계산기

엑셀 파일 형식이 달라도 사용할 수 있는 작은 웹앱입니다.

## 사용 방법

1. `start.bat`을 실행합니다.
2. 브라우저가 열리면 엑셀 파일을 업로드합니다.
3. 시트를 선택합니다.
4. 미리보기에서 `기존금액`이 들어 있는 열을 클릭합니다.
5. 이어서 `할인금액`이 들어 있는 열을 클릭합니다.
6. 필요하면 시작 행과 끝 행을 조정한 뒤 `계산하기`를 누릅니다.

## 특징

- 첫 번째 행이 헤더일 필요가 없습니다.
- 엑셀마다 열 이름이 달라도 됩니다.
- 여러 시트 중 원하는 시트를 고를 수 있습니다.
- 기존금액, 할인금액, 할인률, 총 할인금액을 각각 복사할 수 있습니다.
